# Pip eye comparison baseline

These six face-only SVGs are archived from commit adf4bc6, before the large,
dark-iris eye revision. They are review fixtures, not application assets.
`avatar_review.go` overlays them on the current unchanged base and renders them
with the same 64-pixel GIF quantisation as the new faces. Beaks and brows remain
identical, so each Alt/Neu pair isolates the eye changes.
